# Application Club Website
This repo contains code related to applicationclubmnnit.com

## Steps to Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Application-Club-MNNIT/Application-Club-Website.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Application-Club-Website
   ```

3. **Install all dependencies**: 
   ```bash
   npm run install-all
   ```
   This command installs all necessary packages for both the server and client.

4. **Run the development server**:
   ```bash
   npm run dev
   ```
   This command will concurrently run both the server and client.
